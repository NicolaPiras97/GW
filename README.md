# Nonparametric Bayesian analysis for the Galton-Watson process

This is the code we used for the simulations in the paper "Nonparametric Bayesian analysis for the Galton-Watson process". The code in this version is available for simulation reproducibility purposes only and is an incomplete version of the code necessary to perform full analyses applying the Nonparametric Bayesian analysis for the
Galton-Watson process.

## Usage
To run the simulations launch the sim.R file, which recalls the sim_utilities.R file.
